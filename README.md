# NEPTUN — демонстрационный сайт рыбного хозяйства

## Что находится в проекте
- `index.html` — демонстрационная главная страница NEPTUN.
- Категории: свежая, охлаждённая, замороженная рыба и полуфабрикаты.
- Демонстрационные цены и карточки товаров.
- Форма заявки с тестовым подтверждением (заявки никуда не отправляются).
- Демонстрационные кнопки Telegram и MAX (реальные ссылки ещё не подключены).

## Важно перед публикацией
1. Проверить и заменить демонстрационные фотографии при необходимости.
2. Уточнить настоящий ассортимент и цены.
3. Добавить действующий телефон и адреса Telegram/MAX.
4. Проверить условия и стоимость доставки по Луганску.
5. Подключить безопасный способ приёма заказов. Сейчас форма работает только как демонстрация и ничего не отправляет.

## Как открыть
Откройте `index.html` в браузере или загрузите его в GitHub-репозиторий `neptun`.
Для публикации через GitHub Pages включите Pages в настройках репозитория после загрузки файлов.

## Краткое описание проекта
NEPTUN — рыбное хозяйство: продажа свежей, охлаждённой и замороженной рыбы, а также рыбных полуфабрикатов; доставка по Луганску.

## История текущих решений
- Название: НЕПТУН / NEPTUN.
- Стиль: реалистичная морская тематика, сине-белая палитра, золотистые акценты.
- Вместо корзины — кнопки «Заказать».
- Каталог с демонстрационными ценами за кг.
- Форма заказа на сайте.
- Планируются ссылки на Telegram и MAX.
- Текущий вариант — только демо; не принимать реальные заказы.
